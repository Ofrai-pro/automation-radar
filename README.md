# Automation Radar

Разработал учебный workflow на n8n: RSS-источники, фильтрация, дедупликация, подготовка AI-резюме и интеграция с Telegram. Проект создан с помощью AI-ассистента.

## Практическая задача

Собирать публикации из нескольких источников, отсеивать часть информационного шума и готовить краткое русскоязычное резюме со ссылкой на оригинал.

## Механика

RSS n8n Blog, n8n Releases, OpenAI News и Google Developers → очистка HTML и нормализация → оценка по ключевым словам и дедупликация → Gemini → подготовка текста → Telegram.

Источники запускают отдельные обработки. Скриншот показывает исходную схему с подсказками; из публичного JSON подсказки удалены.

## Файлы

- `automation-radar-template.json` — шаблон для импорта в n8n, без привязок к аккаунтам и реального Telegram chat ID.
- `workflow-radar.PNG` — схема исходного workflow.
- `PORTFOLIO.md` — описание для площадки и сценарий демонстрации.

## Настройка

1. Импортировать JSON в отдельный workflow n8n.
2. Подключить собственные учётные данные Gemini и Telegram через настройки n8n.
3. В Telegram-узле заменить `YOUR_TELEGRAM_CHAT_ID` на свой чат.
4. Проверить обработку одной новости, оставив отправку отключённой.
5. После проверки текста включить Telegram-узел для отправки в свой тестовый чат.

Шаблон не активирован; Telegram отключён. RSS и Gemini требуют интернета. Отобранный текст новости передаётся Gemini. Возможны расходы и ограничения API.

## Что проверено и что осталось

Проверена структура экспортированного JSON и ссылки между узлами.

В одном из запусков источник OpenAI определился как «Неизвестный источник» — это требует диагностики. Запись о просмотренной новости добавляется до Gemini и отправки; обработка ошибок и повторные попытки доставки требуют проверки. Готовым коммерческим внедрением проект не является.

Скриншот доказывает наличие схемы, а не успешную доставку сообщений. В публичный шаблон не включены история запусков, сохранённые новости, привязки к аккаунтам и идентификаторы экземпляра n8n.
